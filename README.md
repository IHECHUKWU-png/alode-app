## 40/60 COMMISSION
Net = Gross - Flutterwave Fee - Refunds - Reversals - Legal Deductions. ADMIN = Net x 40%. CREATOR = Net x 60%. Example: ₦10,000 - ₦150 = ₦9,850 Net. Admin ₦3,940. Creator ₦5,910. Example: ₦100,000 Net = Admin ₦40,000 Creator ₦60,000. Apply to Gifts, Tips, Paid Creator Subscriptions, Eligible Paid Content, Agreed Creator Ads. NOT to wallet deposits, coin purchases, refunds, platform Premium, full ad payments. Per-View NOT split again. Calculate in kobo/cents. Never deduct twice. Never split unverified. Ledger reversals for refunds. Preserve historical rate. Commission % configurable ONLY by Super Admin, default 40%.

## 14B PER-VIEW PAY
Qualified View = 10s+ short, 30s+ long, unique verified user, no self-view, no bot, no VPN. One view per user per video per 24h.
Tier 1 New: ₦200/1000 = ₦0.20/view. Tier 2 10k followers: ₦500/1000 = ₦0.50/view. Tier 3 100k+/Verified: ₦1000/1000 = ₦1/view.
Example: 100k views Tier 2 = ₦50,000. Paid by ALODE from platform revenue, NOT split 40/60 again. 7 days hold. Daily cap ₦50,000. Unlock: 10k followers + 60k mins in 90 days + No violations.

## 14E FREE vs PAID
FREE: Ads every 3-5 videos, 50 videos/day limit, SD, no download. Views count at Base Rate ₦200/1000 from Ad Pool. After 50: "You've reached free limit. Buy Data Pass ₦200 to continue ad-free, or come back tomorrow."
PAID (Data Pass): No ads, HD, download, early access. Views count at Premium Rate ₦500/1000 from Subscription Pool. Worth 2.5x more.
Formula: (Free Views/1000 x ₦200) + (Paid Views/1000 x ₦500). Example: 80k free = ₦16,000 + 20k paid = ₦10,000 = ₦26,000 total.

## 14F WHY ALODE BEATS TIKTOK & FACEBOOK
TikTok: Free+Ads+Fund $0.50-$1/1000 + Gifts 50/50. No Data Pass. No limit.
Facebook: Free+Ads+In-Stream 55% + Stars 70% + Subscriptions. No Data Pass. No limit.
ALODE: Free+Ads+Per-View+Gifts 60/40+Subscriptions+Data Pass+50 videos/day limit. In Africa data is expensive. Data Pass ₦200 feels like buying data. ALODE gives 60%, better than TikTok 50% and Facebook 55%.

## 14G WATCH DATA REDIRECTION - CORE
Normal: User buys data from MTN/Airtel/Glo -> Telco keeps 100% -> Creator gets ₦0.
ALODE: User buys Data Pass inside ALODE via Flutterwave -> Money goes to ONE Global ALODE Pool, NOT to telco -> ALODE 40% / Creator Pool 60% -> Creators paid by views.
Formula: Creator Pay = (Creator Qualified Views / Total Qualified Views That Week) x Global Creator Pool
Example Week: 10,000 users x ₦1000 = ₦10,000,000 Total. ALODE ₦4,000,000. Pool ₦6,000,000. Total Views 1,000,000. Creator A 200k views = 20% = ₦1,200,000. Creator B 100k = 10% = ₦600,000. Creator C 50k = 5% = ₦300,000. No views = ₦0. Views = Money.
Every Monday 00:00, auto job calculates and credits Wallet as "Data Pass Earnings". Creator withdraws via Flutterwave Min ₦5000/$10.
RULE: Never send Data Pass money to telco. Goes to DataPassPool table. Every Qualified View recorded: Viewer ID, Creator ID, Video ID, Watch Duration, Is Paid, Country. Show in Dashboard: "Your Data Pass Earnings This Week: ₦X - From Y Views - Share Z%"
